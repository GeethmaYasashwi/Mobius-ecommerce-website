# Mobius-ecommerce-website


📌 Overview
Mobius is a full-stack e-commerce platform built with the MERN stack. It provides a seamless shopping experience with secure authentication, product management, cart functionality, and payment integration.

🚀 Features

  Product listing
  Add to cart functionality
  User authentication & role-based access (Customer/Admin)
  Cloud image upload with Cloudflare R2
  Interactive dashboards

🛠️ Tech Stack

Frontend
React.js (Vite)
React Router v6
Redux Toolkit & RTK Query
Clerk (Authentication)

Backend
Node.js & Express.js
MongoDB & Mongoose
JWT Authentication
Clerk for secure login & access control
Cloudflare R2 (Image Uploads)
